Hybrid Plan Setup

This page is reserved for the new training plan. It will be built around your Saturday run club long run, muscle retention, home leg work, upper push and pull days, and getting closer to sub-20.

Plan Inputs

  • Saturday long run is fixed
  • Home leg day required
  • Upper push and upper pull required
  • Keep knee load sensible
  • Support fat loss and muscle retention

Plan Goal

This block is designed to move you toward a faster 5K without repeating the same moderate-hard pattern that was blunting progress.

  • Build a real aerobic base so easy days stay easy.
  • Keep one main quality run each week for 5K progress.
  • Retain muscle with home legs plus upper push and pull work.
  • Keep knee load under control and stop stacking fatigue.

Run Rules

  • Easy means conversational, not “steady” and not “a bit spicy.”
  • If HR creeps above about 150 on easy days, slow down or take short walk resets.
  • No back-to-back hard run days.
  • Saturday long run stays mostly aerobic even with the club.
  • If knee pain rises, cut run load before cutting food.

Run Progression

Phase Weeks Main work Long run
Rebuild 1-2 One threshold session per week, more true easy volume 75-90 min easy
Build 3-5 Alternate threshold and 5K reps each week 80-95 min easy
Sharpen 6-7 More race-specific reps, less junk volume 75-90 min controlled
Test 8 Reduced volume, one light quality session, then 5K test Shorter and easy

Tuesday Quality Menu

Weeks 1 and 3

`2 x 10 min` tempo with `2 min` jog, then `4 x 20 sec` strides.

Weeks 2 and 4

`5 x 3 min` at 5K effort with `2 min` easy jog. Hard but controlled.

Weeks 5 and 6

`6 x 800m` at controlled 5K pace with `90 sec` jog, or `8 x 400m` if the knee prefers shorter reps.

Weeks 7 and 8

`3 x 1km` at 5K pace, then taper into a 5K time trial at the end of week 8.

Fueling rules

  • Keep protein high every day to support muscle retention.
  • Push carbs up around Tuesday quality and Saturday long run.
  • Do not force a harsh deficit on workout or long-run days.
  • If recovery drops, add carbs before adding more run intensity.

Checkpoints

  • Easy pace at the same HR should begin to improve.
  • RHR should stay stable rather than trending upward with fatigue.
  • Knee pain should stay mild and non-progressive.
  • Quality sessions should feel sharper because easy days are actually easy.
  • Retest 5K after week 8, not every other week.
